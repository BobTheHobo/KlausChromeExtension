# KlausChromeExtension

Create your own custom Chrome homepage

## Setup

### Prepare Extension 
Note that npm is required
1. Run "npm i" to install the necessary modules
2. Run "npm run build" to webpack the extension

### Load Extension
1. Enable Developer Mode in Chrome Extensions
2. Click "Load unpacked" in the "Manage Extensions" menu
3. Choose the KlausChromeExtension folder
